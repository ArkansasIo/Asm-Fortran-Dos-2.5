# BUSINESS-OS

Unified retro business application built around ASM + FORTRAN + MySQL.

Three unified terminal personalities share the same command/business model:
- SYSTEM/360-inspired mode
- 8-bit mode
- 16-bit DOS mode

Modules include customers, inventory, sales, accounting, invoices, tickets, email, reports, analytics, calculator, users, sessions and audit logging.

The supplied ASM targets modern x86-64 NASM for practical development; SYSTEM/360 is an interface/compatibility-inspired mode rather than native S/360 object code.

See `DOCS/ARCHITECTURE.md` and `BUILD/BUILD.md`.
