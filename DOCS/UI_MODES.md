# UI Modes

BUSINESS-OS exposes one application through three visual/runtime personalities.

## System/360-inspired

Designed around fixed-width terminal screens, command panels, status areas, tabular business data and keyboard-driven navigation.

## 8-bit

Uses compact screens, short commands, constrained fields, simple menus and monochrome-friendly rendering.

## 16-bit DOS

Uses a DOS-style prompt, text menus, keyboard shortcuts, forms and full-screen text applications.

## Shared behavior

All modes expose the same underlying business operations. A customer created in one mode is the same customer seen in every other mode.

## Theme

The default visual identity is green-on-black, while the renderer should support additional foreground/background colors and monochrome palettes.

## Common navigation

`MAIN`, `ACCOUNT`, `CUSTOMER`, `INVENTORY`, `SALES`, `ACCOUNTING`, `INVOICE`, `TICKET`, `EMAIL`, `REPORT`, `ANALYTICS`, `CALC`, `SETTINGS`, `HELP`, `LOGOUT`.
