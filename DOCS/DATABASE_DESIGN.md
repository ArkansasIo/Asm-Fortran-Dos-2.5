# Database Design

## Core entities

`users`, `roles`, `user_roles`, `customers`, `products`, `invoices`, `invoice_lines`, `tickets`, `ticket_messages`, `email_messages`, `email_attachments`, `audit_log`, `account_sessions`, and password-reset records.

## Rules

- Primary keys are stable numeric identifiers.
- Foreign keys enforce relationships.
- Monetary values use fixed-precision decimal types in MySQL.
- Timestamps are generated by the database where appropriate.
- Frequently queried foreign keys receive indexes.
- Deletions of parent records must respect business retention requirements.

## Transactions

Use transactions for invoice creation, payment processing, inventory mutations, accounting postings, and other operations that modify multiple related records.

## Repository boundary

Application code calls repository methods rather than embedding SQL in terminal code. Repositories call prepared statements. The driver owns native MySQL handles and error translation.

## Security

Database accounts follow least privilege. Application users do not receive schema-administration privileges. Credentials are supplied by deployment configuration rather than source files.
